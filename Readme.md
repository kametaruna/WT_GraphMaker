#  ワールドトリガー風 パラメータ＆トリガーセット生成器 (Fanmade)

『ワールドトリガー』のボーダー隊員風パラメータ（レーダーチャート）とトリガーセットカードを作成できる、ブラウザ完結型のWebアプリケーションです。  
オリキャラ（OC）の作成や、二次創作、ロールプレイなどのデータ整理にご活用ください。

##  主な機能

- **隊員データ入力**
  - 隊員名、ポジション（アタッカー、シューター、スナイパー等）の設定
- **トリガーセット編集**
  - 主起動 (MAIN) 4枠 / 副起動 (SUB) 4枠の自由なカスタマイズ
- **8項目パラメータ＆レーダーチャート**
  - 公式準拠の8項目（トリオン / 攻撃 / 防御・支援 / 機動 / 技術 / 射程 / 指揮 / 特殊戦術）に対応
  - 合計値 (TOTAL) の自動計算およびレーダーチャートのリアルタイム描画
- **キャラ画像アップロード**
  - お好みの立ち絵・アイコン画像をアップロード可能
  - クライアント側（ブラウザ）での自動アスペクト比調整＆リサイズ処理
- **高品質カード画像出力 (PNG)**
  - 作成したカードをワンクリックで高解像度PNG画像としてダウンロード保存可能

---

## 🚀 使い方

1. 本リポジトリの [GitHub Pages URL](https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/) にアクセスします。
2. 左側の入力フォームにて、**隊員名・ポジション・トリガー・パラメータ**を入力します。
3. 「ファイルを選択」からお好みのキャラ画像をアップロードします（自動で適正サイズにトリミングされます）。
4. 右側のプレビューカードを確認し、「📷 カード画像を出力 (PNG)」ボタンを押して画像を保存します。
